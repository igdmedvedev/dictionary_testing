# dictionary_testing

Небольшой проект на Java для отработки словарного запаса. Конфигурация задаётся через `application.properties` и может быть переопределена переменными окружения.

## Конфигурация

| Свойство              | Переменная окружения | Обязательный| Описание                                                                 |
| --------------------- | -------------------- | ------------ | ------------------------------------------------------------------------ |
| `words.path`          | `WORDS_PATH`         | +    | Путь к файлу словаря (CSV), из которого загружаются слова.               |
| `word.from`           | `WORD_FROM`          | -          | Индекс **строки**, с которого начать. Значение по умолчанию 1|
| `words.count`         | `WORDS_COUNT`        | -    | Количество слов для обработки/тестирования. Если не задано, то тестируются все слова из файла|

### Пример использования через переменные окружения:

```bash
set WORDS_PATH=C:\dict\words.csv
set WORD_FROM=2
set WORDS_COUNT=10
java -jar Test-jar-with-dependencies.jar
```

### Или инлайном

```bash
java -DWORDS_PATH="C:\dict\words.csv" -DWORD_FROM=2 -DWORDS_COUNT=10 -jar Test-jar-with-dependencies.jar
```

## Сборка

```bash
mvn package
```

В результате создаётся исполняемый JAR с зависимостями
